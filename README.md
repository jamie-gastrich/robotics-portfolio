# robotics-portfolio

An index of my robotics work, plus smaller standalone exercises in C++ and Python.

## Background
About ten years as a professional software engineer (C#, JavaScript, Node.js, backend and integration work), with several years in warehouse automation and controls systems: PLC/HMI work, integrations, startup and troubleshooting of automated systems. I'm now building hands-on robotics experience in ROS 2, C++, Python, Gazebo, Linux, and Docker.

## Projects

| Project | What it is | State |
|---|---|---|
| [`mower-sim`](https://github.com/jamie-gastrich/mower-sim) | A ROS 2 simulation of an autonomous fairway mower: GNSS localization, stripe planning, path tracking, safety, perception, and command and control, moving from a 2D sim to Gazebo. | just started |
| [`robotics-factory`](https://github.com/jamie-gastrich/robotics-factory) | The lab where I learned ROS 2 basics: a heartbeat publisher and a turtlesim rescue game with 84 logic tests that run without a ROS graph. | paused; active work moved to `mower-sim` |
